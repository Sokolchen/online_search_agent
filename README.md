# online_search_agent

-本项目是基于网络教程与后续全栈知识补全，编写的一个使用LangChain作为基础架构的集成了包括本地PDF-RAG就解析实现多源回答的的Agent。



# 已实现的功能

##1.基于智谱AI 联网搜索工具API实现的基础联网查找功能

-用户可对智能体直接对话要求查找"相关""最新"信息，引入`datetime`变量，确保查询时携带正确的时间信息，减少日期错乱现象，提升搜索结果的时效性。

##2.基于bs4与WebBaseLoader实现的简单推文网站爬取功能

-用户可提供指定网站并让智能体爬取内容，支持用户直接在对话中提出要解析的类名以提升精确度与效率，即按照自定义CSS类名的过滤。

##3.基于开源工具OpenDataLoaderPDFLoader与OpenAIEmbeddings实现的本地PDF文件解析+向量化存储的具有RAG问答管理功能的本地Chroma向量知识库存储功能

-管理查询功能

--对智能体提出“查询本地向量库/查询本地PDF存储”等文本，可查看本地向量管理情况与其对应PDF

-添加/删除功能

--在与智能体对话时，提出“添加PDF/向量文件”，在对话中给出系统绝对路径以添加本地pdf文件

--提出“删除PDF”并给出完整pdf名，将删除pdf对应的向量文件（在文件名未完全匹配时会列出本地现有向量库来供用户查阅）

-对话查询知识功能

--当用户提出问题时，智能体首先尝试使用本地知识库工具回答问题，实现本地数据问答。
